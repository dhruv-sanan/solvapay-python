# Support

This is a **community SDK** — no SLA, no on-call.

## Getting help

- **Questions / ideas:** [GitHub Discussions](https://github.com/dhruv-sanan/solvapay-python/discussions)
- **Bugs:** [Open an issue](https://github.com/dhruv-sanan/solvapay-python/issues)
- **Official adoption proposal:** [solvapay/solvapay-sdk#187](https://github.com/solvapay/solvapay-sdk/issues/187)
- **SolvaPay platform support:** contact SolvaPay directly at [solvapay.com](https://solvapay.com)
